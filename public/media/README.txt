# Pasta Pública para Mídias e Vídeos do Portfólio

Você pode colocar suas fotos e vídeos diretamente dentro desta pasta `/public/`:

Exemplos:
1. Fotos:
   - Se você colocar `minha-foto.jpg` nesta pasta, no site basta usar `/minha-foto.jpg`.
   - Se colocar em `/public/media/foto1.jpg`, no site basta usar `/media/foto1.jpg`.

2. Vídeos:
   - Se colocar `meu-video.mp4` nesta pasta, no site basta usar `/meu-video.mp4`.
   - O player suporta MP4, WebM e também links do YouTube e Vimeo!
